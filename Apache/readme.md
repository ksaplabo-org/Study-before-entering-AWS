## ApacheのWebサーバー

正式名所：Apache HTTP Server  
- Webサーバー
- オープンソース
- Windows、Linuxなどで使用可


## LinuxにおけるApache

Linuxでhttpdと呼ばれるものは、「Apache HTTP Server」であり  
Apacheの実行ファイル名＝httpdである  


## Apache Tomcat  

Apacheでよく聞くのはTomcatだが  
TomcatはJavaで作ったWebアプリを動かすエンジン（アプリケーションサーバー）であり  
Linuxのhttpdとは用途が違う。  


Apache＝Apache Software Foundation(ASF)という団体名の略  
この団体が以下のソフトを作成している  
- Apache HTTP Server
- Apache Tomcat
- Apache Kafka
- Apache Spark
- Apache Hadoop
- Apache Maven
などなど
